# 단청은 2013 복구 때 의도한 색으로 칠한다

**맥락:** 숭례문 단청(모로단청)은 2013년 복구 직후부터 박락·균열이 생겼고, 2014년 감사원이 재시공을 통보했지만 2022년 보도까지 다시 칠하지 못했다. ADR 0001은 "지금 가서 볼 수 있는 모습"을 기준으로 삼는다.

**결정:** 형태는 ADR 0001대로 복구 이후 모습이지만, 단청 색은 현장의 훼손된 상태가 아니라 복구 때 의도한 색으로 칠한다.

**이유:** 훼손은 고증 대상이 아니라 시공 결함이고, 재단청되면 다시 바꿔야 한다. 문양 도판(공공누리 1유형)도 의도한 단청을 그린 것이라 서로 맞는다.
