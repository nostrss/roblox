# 지붕 기와는 기와골 메시로 굽고, 처마 끝 막새만 한 장씩 놓는다

**맥락:** 숭례문 복구 때 쓴 기와는 암키와 14,414장·수키와 6,336장이다(S7 p.396~397). 거기에 막새까지 더하면 2만 장이 넘는다. 한 장씩 파트나 메시로 놓으면 문루 하나가 부재 수와 그리기 비용을 거의 다 쓴다. 그런데 걷는 거리에서 장 단위로 보이는 기와는 처마 끝 막새뿐이다.

**결정:** 지붕 몸체 기와는 15번의 기와골 메시(수키와 줄·암키와 골을 곡면에 같이 구움)로 처리한다. 처마 끝 수막새·암막새만 굽기 도구가 적은 자리에 한 장씩 놓는다(지금은 기본 파트, 문양 메시는 나중). 마루·잡상·취두·용두·토수는 자료의 위치·개수·크기에 맞춘 블록으로 두고, 메시 자료가 생기면 바꾼다.

**이유:** 메시 4개와 막새 약 900장으로 실루엣과 처마 끝이 실제와 맞는다. 다음 랜드마크에서도 곡선 데이터와 간격만 바꾸면 그대로 쓸 수 있다.
