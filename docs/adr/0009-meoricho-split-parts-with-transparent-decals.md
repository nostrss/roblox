# 머리초는 부재를 세 Part로 나눠 투명 PNG Decal로 붙인다

**맥락:** Decal은 붙인 면 전체에 그림 한 장을 맞춰 늘린다. 창방·평방·도리를 칸 하나 또는 면 한 줄 Part에 두고 머리초를 붙이면 칸 길이(협칸 3.848 m, 어칸 7.080 m)마다 문양 비율이 달라진다.

**결정:** 머리초가 들어가는 부재는 기둥 자리 사이 칸마다 [머리초 | 계풍 | 머리초] Part로 나눈다. 머리초 Part 길이는 면 높이에 비례시켜 그림 비율과 늘 같게 한다. 그림은 뇌록 바탕을 투명하게 구운 PNG Decal로 붙이고, 조각도 원래 부재 이름(Part.Name)을 그대로 쓴다. Decal은 뒤집을 수 없으므로 한쪽 끝 그림과 거울상 그림을 따로 올린다.

**이유:** 같은 그림 몇 장으로 모든 칸 길이·층(높이만 다름)에 늘어남 없이 쓸 수 있다. 바탕이 투명하면 가칠 색(Palette)을 바꿔도 그림을 다시 올리지 않는다. 이름이 같으므로 Palette 칠과 지붕 분해 겹 매핑은 고치지 않아도 된다. 칸 길이별로 그림을 따로 굽는 안은 그림 수가 늘고, SurfaceGui 안은 면마다 GUI가 생겨 무거워서 기각했다.
