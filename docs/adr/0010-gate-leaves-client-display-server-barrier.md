# 판문은 클라이언트에서 돌리고, 길은 서버의 보이지 않는 막이로 막는다

**맥락:** 개폐의식에서 판문이 닫혔다 열린다. 방문자가 문 자리에 서 있어도 밀리거나 끼이거나 튕기면 안 되고, 도중 접속자도 같은 장면을 봐야 한다.

**결정:** 서버의 문짝은 늘 열린 자리에 두고 부딪힘을 끈다. 각 클라이언트가 서버 시작 시각에서 계산한 각도로 자기 화면에서만 돌린다. 열린 자리 부딪힘은 보이지 않는 벽이 늘 맡고, 닫힘 구간에는 서버가 보이지 않는 막이의 CanCollide를 켜되 그 자리에 사람이 있으면 비울 때까지 미룬다.

**이유:** 부딪히는 문을 물리나 서버 트윈으로 움직이면 사람을 밀어낸다. 표시와 판정을 나누면 밀림이 없고, 각도가 시각만의 함수라 도중 접속 상태도 저절로 맞는다.
