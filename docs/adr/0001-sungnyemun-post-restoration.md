# 숭례문은 2013 복구 이후 모습으로 재현한다

**맥락:** 자료가 2006 정밀실측(화재 전, S1·S2), 2012 3D 정보구축 도면(복구 공정, S4), 2013 해체실측보고서(S3)에 걸쳐 있다. 섞어 쓰면 하층 처마 높이가 약 0.1m 어긋났다.

**결정:** 복구 이후(S4·S3의 복구 후 값)를 기준으로 하고, 2006 값은 S4에 없는 치수를 채울 때만 쓴다. 이 경우 `Dimensions.luau` 주석에 명시한다.

**이유:** 방문자가 지금 가서 볼 수 있는 모습이고, 부재 단위 도면(S4)이 복구 기준이라 디테일 작업 자료와 맞는다.
