# 주변 풍경과 인물은 생성한 텍스처와 ID로 불러오는 메시로 코드가 짓는다

**맥락:** 주변 건물·하늘·조경이 빈약하다는 지적을 받았다. 사진 텍스처는 라이선스 규칙(공공누리 1유형 또는 직접 촬영)에 막히고, 상점 나무 모델을 Studio에 넣으면 저장을 잊었을 때 사라지며 git에 남지 않는다.

**결정:** 하늘 큐브맵과 건물 입면·박석·철엽은 `tools/`의 생성기로 만들어 업로드하고 에셋 ID만 코드에 둔다. 나무는 공개 메시, 인물·차는 Studio AI로 생성한 메시의 ID를 (AI 나무는 만화처럼 나와 쓰지 않았다) 데이터에 적어 서버가 `CreateMeshPartAsync`로 받고, 인물·차는 클라이언트가 그 원본을 복제한다(core `Meshes`). 건물 창 불빛은 스스로 빛나는 SurfaceGui다.

**이유:** 전부 코드와 생성기로 다시 만들 수 있고 Studio 저장에 기대지 않는다. 대신 `SurfaceAppearance`를 코드로 만들 수 없어(공개 그림은 거부된다) 메시에 법선·거칠기 맵이 없다. 더 사실적인 재질이 필요하면 Studio에 PBR 모델을 두는 방식으로 바꾼다.
