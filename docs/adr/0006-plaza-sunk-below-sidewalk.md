# 광장 바닥은 문 앞을 가장 낮게, 둘레 보도·도로는 한 기울어진 면으로 둔다

**맥락:** 지면 표고 자료가 없다(plaza-notes 4절). 처음에는 광장·도로를 평지에 연석 0.15 m로 두기로 했지만, 항공 사진과 수리보고서(S7 p.589~590: 육축 전면 ↔ 전면 출입구 2.49 m, 후면 ↔ 배면 출입구 1.14 m)로 광장이 둘레보다 낮다는 것이 확인됐다.

**결정:** 문루 지면(홍예 통로 바닥)을 Y 0으로 두고, 광장 바닥은 육축 앞뒤 평지에서 두 출입구까지 건물 축 Z 방향으로만 오르는 그릇으로 만든다. 둘레 보도는 두 출입구 높이를 지나는 한 기울어진 면, 차도는 그보다 연석 0.15 m 아래다. 광장이 보도보다 낮은 가장자리는 광장 옹벽으로 받는다. 출입구 두 곳은 연석 한 단 차이로 걸어 나간다.

**이유:** 자료에 있는 두 레벨차만으로 높이를 정하고 나머지는 선형으로 채워, 높이 함수 두 개(`Plaza.floor`, `Plaza.sidewalk`)가 바닥·옹벽·성곽 단부·스폰 높이를 모두 결정한다. 표고 자료가 생기면 이 두 함수만 바꾼다. 평지 + 연석 안은 사진과 맞지 않아 기각했고, Terrain으로 다듬는 안은 Studio 작업이라 코드 뼈대와 따로 둔다.
