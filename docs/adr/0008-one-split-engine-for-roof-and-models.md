# 지붕 분해와 모형 분해는 하나의 분해 엔진을 쓰고, 겹을 나누는 방식만 부르는 쪽이 정한다

**맥락:** 공포 모형 분해는 지붕 분해와 같은 소리·접촉 판정·제자리 복원을 원한다(사용자가 귀로 확정한 동작). 그런데 겹을 정하는 방식(지붕은 부재 Attribute 겹·층, 모형은 부재 밑면 높이)과 벌어지는 순서(지붕은 위 겹부터, 모형은 아래 겹부터)는 다르다.

**결정:** core `Split`이 움직임·접촉 소리·제자리 복원·프롬프트·멀어지면 조립을 맡고, 부르는 쪽은 `collect`로 "겹 목록(아래 → 위)과 겹마다 단계별 오르는 높이"만 넘긴다. 지붕은 core `RoofSplit`이 Attribute로 이 목록을 만들고, 모형은 `Split.byBottom`으로 밑면 높이로 나눈다(아래 겹부터 그 겹과 위 겹 전체를 함께 들어 올림). 어느 분해인지는 표식 태그(`RoofSplitMarker` / `ModelSplitMarker`)로 가른다.

**이유:** 귀로 맞춘 소리 동작을 한 곳에만 두어야 다음 랜드마크의 지붕·모형도 같은 느낌이 난다. 모형을 아래 겹부터 벌릴 때 겹마다 따로 띄우면 아래 겹이 위 겹을 뚫고 지나가므로, 겹 Y를 "단계별 오름의 합"으로 두어 두 방식을 같은 식으로 표현했다. 지붕 엔진을 복사해 모형용을 따로 두는 안은 소리 규칙이 갈라질 수 있어 기각.
