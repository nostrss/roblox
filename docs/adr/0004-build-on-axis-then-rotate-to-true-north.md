# 건물은 자기 축으로 짓고, 건물 자리 값으로 실제 방위에 돌려 놓는다

**맥락:** 숭례문 정면은 정남이 아니라 방위각 222°(정남에서 서쪽으로 약 42°)다(OSM 바닥·홍예 통로선·위성 영상 용마루가 일치). 지금까지의 공포·축부·처마 코드는 건물 축을 X·Z축에 맞춰 짓는다. 대부분의 랜드마크도 정남향이 아니다.

**결정:** 세계 좌표는 진북 = -Z로 두고, 건물은 자기 축(정면 = +Z)으로 지은 뒤 Place마다 건물 자리(위치·정면 방위각) 값 하나로 통째로 돌려 놓는다. 지도에서 가져오는 광장·도로·주변 건물은 세계 좌표 그대로 둔다.

**이유:** 해·그림자 방향과 지도 자료가 실제와 맞고, 건물 코드는 축 정렬 그대로 재사용된다. 세계 전체를 건물 축에 맞추는 안(지금 코드 그대로)은 해 방향이 틀어지고 지도 자료를 매번 돌려 넣어야 해서 기각.
