# 시간대는 실제 서울 시각을 따르고, 방문자가 바꾸면 자기 화면에만 적용한다

**맥락:** 하늘·빛을 서버 하나의 시각으로 돌리면 모두 같은 장면을 보지만, 방문자가 노을·밤을 보고 싶을 때 다른 사람의 화면까지 바뀐다. 서버가 `Lighting.ClockTime`을 쓰면 그 값이 복제돼 클라이언트에서 바꾼 시각을 덮어쓴다.

**결정:** Lighting의 시각·색조·효과와 야간 조명 켜고 끄기는 클라이언트(core `TimeOfDay`)만 다룬다. 기본은 서버 시계(`workspace:GetServerTimeNow()`)로 계산한 실제 서울 시각(KST)이고, 방문자가 "노을/밤"을 고르면 그 화면만 정해진 시각으로 바꾼다. 서버는 Lighting 시각을 쓰지 않는다.

**이유:** 실제 시각을 따르면 "지금 숭례문"을 보는 경험이 되고, 개인 선택은 남에게 영향이 없다. 서버 시계를 쓰므로 기기 시계가 틀려도 모두 같은 서울 시각을 본다. 서버 공용 낮밤 주기 안은 개인 선택과 충돌해 기각.
